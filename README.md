

## Что нужно

- Node.js 22.12 или новее в ветке 22 LTS. Установленный Node.js 22.17.1 подходит.
- VS Code и терминал PowerShell.
- Для входа, регистрации, профиля и бронирований — отдельно запущенный бэкенд с базой данных. В примере его адрес: `http://localhost:8080`.

Для запуска самого фронтенда Java и Docker не требуются. Без работающего API страница и карта откроются, но действия с аккаунтом и бронированиями будут недоступны.

## Первый запуск в VS Code — Windows / PowerShell

### 1. Открыть папку проекта

В VS Code выбрать **File → Open Folder** и открыть `C:\Twiy_hub` либо саму папку фронтенда. Затем выбрать **Terminal → New Terminal**, тип терминала — **PowerShell**.

Перейти в папку, в которой лежит фронтендовый `package.json`:

```powershell
cd C:\Twiy_hub\TviyHub-frontend
```

Если распаковал проект в другое место, нужно подставить свой путь. НЕ ЗАПУСКАТЬ npm из общей папки `Twiy_hub` или из папки бэкенда.

### 2. Проверка Node.js и npm

```powershell
node --version
npm.cmd --version
```

Если команды не найдены после установки Node.js, полностью закрыть и снова открыть VS Code.

В командах ниже используется `npm.cmd`: в PowerShell он работает без изменения политики выполнения скриптов Windows.

### 3. Установить зависимости

```powershell
npm.cmd ci
```

 Установка нужна после распаковки проекта или изменения `package-lock.json`, а не при каждом запуске.

### 4. Создать локальные настройки

Эта команда скопирует пример, только если файла `.env.local` ещё нет:

```powershell
if (!(Test-Path .env.local)) { Copy-Item .env.example .env.local }
```

Открыть `.env.local` в VS Code. Для локального бэкенда оставь:

```dotenv
API_PROXY_TARGET=http://localhost:8080
VITE_API_BASE_URL=/api
```

`API_PROXY_TARGET` — адрес работающего Java-сервера, без `/api` в конце. `VITE_API_BASE_URL=/api` менять не нужно: браузер отправляет запросы на свой фронтенд, а Vite перенаправляет их на бэкенд.

Настройки MySQL, JWT и почтовые пароли во фронтенд не копируй. Переменные с префиксом `VITE_` доступны браузеру и не подходят для секретов.

### 5. Запусти фронтенд

```powershell
npm.cmd run dev
```

Открой **http://localhost:5173**. Если этот порт уже занят, Vite напечатает другой адрес — используй именно его.

Терминал должен оставаться открытым. Сервер продолжает работать и не возвращает строку ввода — это нормально. Для остановки нажми **Ctrl+C**.

## Как запустить повторно

Если зависимости и `.env.local` уже есть, достаточно:

```powershell
cd C:\Twiy_hub\TviyHub-frontend
npm.cmd run dev
```

Бэкенд и база запускаются отдельно. После изменения `.env.local` останови фронтенд через Ctrl+C и запусти снова.

## Как обновить фронтенд из нового архива

1. Останови только терминал фронтенда через Ctrl+C.
2. Распакуй содержимое папки `TviyHub-frontend` из архива в свою одноимённую папку с заменой файлов. Не создавай вложенную `TviyHub-frontend/TviyHub-frontend`.
3. Сохрани свой `.env.local`. В архиве его нет — есть только `.env.example`.
4. Если обновился `package-lock.json`, выполни `npm.cmd ci`.
5. Снова выполни `npm.cmd run dev` и обнови страницу браузера.

## Частые проблемы

| Что видно | Что проверить |
| --- | --- |
| `ENOENT`, не найден `package.json` | Перейди в папку фронтенда через `cd` и повтори команду. |
| PowerShell запрещает выполнение `npm.ps1` | Используй `npm.cmd`, как в примерах выше. |
| Не найден `vite` | Выполни `npm.cmd ci` в папке фронтенда. |
| Страница есть, но вход и бронирование не работают | Проверь, что Java-бэкенд работает на адресе из `API_PROXY_TARGET`, а база доступна ему. |
| `ECONNREFUSED` или `proxy error` в терминале | Vite не может подключиться к бэкенду. Проверь его запуск и порт. |
| После изменения адреса API ничего не изменилось | Перезапусти `npm.cmd run dev`: настройки окружения читаются при запуске. |
| Карта не загрузилась | Для Google Maps нужен интернет и доступ к Google; ссылка под картой открывает локацию отдельно. |

## Проверки и сборка

```powershell
npm.cmd test
npm.cmd run build
```

Сборка создаёт `dist/client` и серверный шлюз `dist/server/index.js`. Не открывай `index.html` двойным кликом из проводника — используй dev-сервер или веб-сервер со сборкой.

`npm.cmd run preview` показывает собранный интерфейс, но сам по себе не настраивает `/api`-прокси для полноценной проверки связи с бэкендом. Для локального тестирования используй `npm.cmd run dev`.

## Дополнительно: фронтенд в Docker

Этот вариант необязателен. Если Docker уже установлен, а Java работает на компьютере на порту 8080:

```powershell
docker compose -f compose.frontend.yml up --build
```

Открой **http://localhost:3000**. Этот compose запускает только фронтенд в nginx, без Java и MySQL. По умолчанию запросы API идут на `http://host.docker.internal:8080`. Java должна быть доступна из сети контейнера; если это не настроено, используй обычный запуск Vite выше.

## Что входит в интерфейс

- Рабочие места и тарифы из API; проверка занятости выбранного интервала.
- Вход, регистрация, подтверждение почты и восстановление пароля.
- Почасовое и дневное бронирование, месячный абонемент.
- Запрет бронирования на прошедшие часы по времени Киева, в том числе при долго открытой форме.
- Профиль, история, повтор и отмена брони с проверкой правил сервером.
- Админ-панель для аккаунтов с серверной ролью ADMIN.
- Google Maps с отметкой Tviy.hub по адресу в макете.

Оплата сейчас предусмотрена администратору. Полноценный Stripe-поток ограничен контрактом API: клиент не получает `paymentId` созданной брони.
